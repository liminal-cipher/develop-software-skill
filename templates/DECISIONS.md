# 주요 결정

> 결과에 영향을 주는 중요한 선택만 기록한다. 단순한 구현 세부사항은 남기지 않는다.

## [결정 제목]

- 상태: 제안 / 확정 / 대체됨
- 문제 상황: [이 선택을 하지 않으면 실제로 어떤 문제가 생기는가? 구체적인 상황으로 설명한다.]
- 선택한 방법: [기술 이름보다 먼저 실제 동작을 설명한다.]
- 선택 이유: [요구사항, 운영 조건, 성능, 유지보수 측면에서 적합한 이유]
- 다른 방법: [검토한 대안과 선택하지 않은 이유]
- 구현 위치: [파일과 함수 또는 관련 설정]
- 확인 방법과 결과: [실제로 실행한 검사와 관찰 결과. 아직 확인하지 않았다면 NOT RUN으로 표시]
- 한계와 다시 검토할 조건: [무엇을 보장하지 않는지, 어떤 조건에서 다시 판단할지]

필요한 항목만 남긴다. 제안과 확정된 결정을 구분하고, 결정이 바뀌면 이전 내용을 덮어쓰지 말고 대체된 이유를 짧게 남긴다.
