# 작업 기록

> 모든 대화나 사소한 수정은 기록하지 않는다. 나중에 다시 알아야 할 중요한 단계나 장애만 남긴다. 현재 상태는 CURRENT_TASK.md에서 관리한다.

## [날짜 또는 작업 시점] [단계·문제 제목]

- 상황: [무슨 일이 있었는가?]
- 확인한 근거: [실제 오류, 로그, 입력, 실행 결과 또는 파일]
- 원인: [확인된 원인. 추측이면 추측이라고 표시]
- 변경: [수정한 파일과 핵심 내용]
- 다시 확인한 결과: [같은 조건으로 실행한 결과 또는 NOT RUN]
- 남은 영향: [추가 조치나 재검토가 필요한 부분]

필요한 기록이 없으면 이 문서를 만들지 않는다. 완료된 기록을 CURRENT_TASK.md에 다시 복사하지 않는다.
